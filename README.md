# notes-editor

Простой редактор заметок для одного человека на одном устройстве.

## О проекте

Границы проекта, сценарии и список поддерживаемой разметки описаны в [docs/scope.md](docs/scope.md).

## Как открыть проект

1. Склонируй репозиторий: `git clone https://github.com/halimaaltyn2026/notes-editor.git`
   Или нажми Code → Download ZIP и распакуй архив.
2. Открой папку проекта в VS Code.
3. Открой файл `index.html` в браузере: двойной клик по файлу.
   Или в VS Code нажми правой кнопкой на `index.html` → Open with Live Server (если стоит расширение Live Server).

Код редактора будет добавлен на следующих этапах.


## Где хранятся заметки

Заметки хранятся в браузере под именем `notes-editor-notes`.
