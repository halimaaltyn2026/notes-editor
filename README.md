# notes-editor

Простой редактор заметок для одного человека на одном устройстве.

## О проекте

Границы проекта, сценарии и список поддерживаемой разметки описаны в [docs/scope.md](docs/scope.md).

## Как открыть проект

1. Скачай или склонируй репозиторий.
2. Открой папку проекта в VS Code.

Код редактора будет добавлен на следующих этапах.
